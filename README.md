# ZUNO

واجهة اجتماعية عربية RTL مبنية بـ React + Vite ومتصلة بمشروع Supabase مستقل.

## التشغيل
1. انسخ `.env.example` إلى `.env.local`.
2. ضع رابط Supabase ومفتاح **publishable** فقط.
3. نفّذ `npm install` ثم `npm run dev`.

## الأمان
- لا تضع أبداً `service_role` أو secret key في الواجهة أو GitHub.
- صلاحيات الوصول للبيانات تعتمد على RLS في Supabase.
- لا توجد بيانات اعتماد سرية محفوظة في المستودع.

## الحالة
النسخة الأولية تشمل التسجيل/الدخول، الملف الشخصي، البحث، طلبات الصداقة، المحادثات النصية والإشعارات بحسب السياسات المفعلة. لم يتم اختبارها بحسابين حقيقيين بعد. لا توجد غرف صوتية أو ألعاب في هذه المرحلة.
